## Selected projects

### DischargeIQ (working title)
**Solo project, November 2026** · [Live app](https://dischargeiq-pied.vercel.app) · [Code](https://github.com/21walel-DATA/dischargeiq)

A web app for community pharmacy teams handling NHS Discharge Medicines Service (DMS) referrals. It compares a patient's medicines before admission with their hospital discharge letter, shows what was started, stopped or changed, and ends with a claim-ready record.

- **The problem came from user research.** A pharmacist told me each comparison takes 15 to 20 minutes, and that they submit no DMS claims (worth up to £35 each) because the claim process is too slow.
- **"AI reads, code compares, the pharmacist approves."** Claude extracts medicines from the letter (or from a PDF or photo of it), deterministic code does the comparison, and every flagged line must be checked and initialled before a stage can be completed.
- **Safety rules from my pharmacy experience:** high-risk medicine flags based on the UK APINCHS framework, medicines missing from a letter flagged for review, and no fuzzy matching of drug names, because look-alike names are a known cause of errors.
- **Evidence:** 203 automated tests, 42 of 42 manual tests passed on the live site, Lighthouse accessibility 100 on every page, two independent security reviews, and a clinical hazard log.
- **My role:** I chose the problem, ran the user research, made and logged 57 product and architecture decisions, wrote the clinical rules, reviewed the hazard log, and tested every user journey. I used Claude Code as my coding assistant and reviewed every change.

`TypeScript` `React` `Node.js` `Express` `PostgreSQL (Supabase)` `Zod` `Vitest` `GitHub Actions` `Vercel` `Render` `Claude API`
